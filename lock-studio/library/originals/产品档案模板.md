# 产品档案模板（任何衣服都按这个填）

复制到原图目录的 `spec.md` 里「### 衣服」那一节，逐项填。不会写可以让 Codex 先看照片按这个模板写一版，自己再对着照片检查一遍。

**为什么要这么细**：实测里衣服的颜色和大概样子都能对，走样全出在两类地方：
1. **最有辨识度的那个设计**：只写"有一块长叠片"，就被画成了丝巾。
2. **特殊材质**：长毛、粗针、混色、半透明。模型会把绒毛抹平、把混色画成均匀的灰、把半透明画成不透。

所以这两块要写成"看照片的人能直接拿来对的描述"，再列成检查要点。

照片要求：
- `front.jpg` 正面、`back.jpg` 背面（平铺或挂拍，纯色背景）
- `detail_1.jpg` 面料近拍，要平铺拍：不要把布拧成卷圈或堆成大褶，模型会把卷圈当成图案
- `detail_2_<部位>.jpg` 关键设计近拍，比如领口、缝线、扣子口袋；没有就从 front.jpg 裁出来放大

### 衣服（以 front.jpg、back.jpg、detail_*.jpg 为准）
- 品类：【圆领套头毛衣 / 翻领外套 / 衬衫……】
- 颜色：【颜色名 + 近似色号，全身是否同一个颜色；混色写清几种颜色、各占多少】
- 材质（特殊材质写细，见下方"材质怎么写"）：
  - 面料和织法：【细针 / 粗针 / 平纹 / 罗纹 / 梭织……】
  - 表面：【哑光 / 微光泽 / 亮面】
  - 绒毛：【没有 / 短绒 / 长毛约 X mm，顺着什么方向，边缘轮廓是否被绒毛弄得毛茸茸】
  - 透光：【不透 / 略透（能隐约看到身体轮廓）/ 透】
  - 厚薄和垂坠：【薄软贴身 / 厚实蓬松 / 挺括有型】
- 版型：【宽松 / 合身 / 短款 / oversize】，肩线【正肩 / 落肩 / 插肩】
- 长度：衣长落在【腰 / 胯骨 / 臀下 / 大腿中部】，袖长到【手腕 / 盖住半个手背】，袖口【收紧 / 直筒 / 喇叭】
- 领口：【圆领 / V 领 / 翻领 / 立领】，用身体当尺子写多高多宽，罗纹多宽
- 门襟和扣子：【没有 / X 颗，颜色材质，从哪到哪，间距】
- 口袋：【没有 / 类型 + 数量 + 在身体哪个位置 + 多大】
- 缝线和收边：【外露缝线、明线、罗纹边（领口 / 袖口 / 下摆各多宽）】
- 关键设计（这件衣服最有辨识度的 1~2 处，用几何写法）：
  - 起点：从哪里开始、和什么连在一起
  - 形状和大小：用身体当尺子（"约一个手掌宽"），宽度变不变
  - 走向和终点：贴身还是飘起，到哪里结束
  - 它不是：最容易被画成的样子都写进去
- 侧面看：【侧身时能看到什么、不能出现什么】
- 背面：【素面 / 有什么】
- 不能出现：【印花、logo 文字（领标不要画）、多出来的口袋扣子、颜色偏到 XX……】

### 检查要点（放大逐条看）
必过（任何一条不对判 C，返工）：
1. 【颜色】
2. 【材质：绒毛长短 / 针织粗细 / 混色颗粒 / 透光，和 detail_1 并排看】
3. 【廓形、衣长和袖长】
4. 【领型、关键设计的形状和位置】
5. 【扣子、口袋这些数得出来的东西，逐个数】
尽量（不对评 B，写进报告，不返工）：
6. 【一两厘米的小结构：缝线拐角、罗纹宽度、明线】

### 材质怎么写（特殊材质最容易被画错）
| 材质 | 要写清楚 | 模型最常画错成 |
|---|---|---|
| 长毛（马海毛、羊驼毛、貂绒） | 毛长几毫米、毛是顺的还是蓬的、轮廓边缘毛茸茸、底下看不到织纹 | 抹平成普通毛呢或抓绒；变成动物皮草；毛太长像玩偶 |
| 细绒针织 | 表面一层很短的细绒、隐约能看到细针眼、柔和不反光 | 光滑棉 T 恤；粗针毛衣 |
| 粗针 / 混色纱 | 针眼大小（"一针约小指甲宽"）、几种颜色的纱拧在一起、颗粒是碎点不是条纹 | 均匀的单色灰；横条纹；细针 |
| 半透明 | 透到什么程度、透出的是身体还是内搭 | 完全不透 |
| 缎面 / 光泽 | 光泽强弱、褶皱处才有高光 | 亮面塑料感；哑光 |
| 外露缝线 | 缝线是凸起的一道棱、走向从哪到哪 | 缝线消失；画成普通插肩缝 |
