# 模特档案：示例模特

复制这个文件夹，改成模特的名字（比如「小美」），放入她本人的照片，再改写下面的描述。这个文件夹只放这个人，和衣服无关，任何衣服都能配她出图。

照片（文件名要一模一样；大头照要求脸占画面一半以上、纯色背景、光线均匀、不戴眼镜帽子）：
- `face_1_front.jpg` 正脸
- `face_2_half.jpg` 半侧脸（转头约 45°）
- `face_3_profile.jpg` 全侧脸（转头 90°）
- `face_closeup.jpg` 正脸特写，只包含额头到下巴（可以从 face_1 裁）
- `body_1_front.jpg` 正面全身照（可选）

缺哪个角度，素材图是那个角度时脸最容易不像。

## 固定特征（出图时必须保持）
- 脸型：【圆脸 / 鹅蛋脸 / 方脸，下颌角和下巴的形状】；不是瓜子脸、不是 V 脸
- 眉毛：【平直 / 弯，颜色，粗细】
- 眼睛：【形状、单双眼皮宽窄、眼距】
- 鼻子：【鼻梁高低、鼻头大小】
- 嘴唇：【厚薄、嘴大小】
- 皮肤：【肤色，有没有雀斑痣】，保留皮肤质感，不要磨皮
- 侧脸：【额头斜度、鼻梁弧度、下巴前后】
- 妆容：【眼线、眼影、腮红、口红颜色】
- 头发：【颜色、长度、分缝、刘海、卷还是直】
- 不要：瘦脸、尖下巴、高鼻梁、放大眼睛、欧式深双眼皮、网红脸
