# 产品规格：示例款

拍细节图的建议：面料肌理、印花或 logo、领口、袖口、下摆、扣子各拍一张特写，图越清楚，锁得越准。

## 锁定参数
- 品类：连衣裙
- 材质：100% 棉，哑光，中等厚度，表面有细小的斜纹肌理
- 颜色：主色奶油白 #F3EDE2，碎花为雾霾蓝 #7A8FA6 和橄榄绿 #8A8F5C
- 版型：收腰 A 字，腰线在自然腰位
- 长度：裙摆下沿在膝盖下方约 10cm，袖长到手肘
- 领型：方领，领口宽约到锁骨中段
- 纹路和印花：小碎花均匀满印，单朵花约指甲盖大小，方向随机
- 细节：前胸有 4 颗白色贝壳扣，竖排；腰后有同色系带；两侧没有口袋
- 不能出现：口袋、褶边、亮面光泽、碎花变大
