# 小红书锁图工作台：使用说明

用 ChatGPT 桌面版里的 Codex 和 GPT 订阅出小红书穿搭图。你给一张想模仿的小红书图（素材图），它出一张同样动作、同样场景的图：**衣服换成我们的产品，脸和发型换成我们的模特**，衣服的颜色、材质、款式、长度和模特的脸都锁住不变。

一张图大约 10 分钟（换衣服约 3 分钟，换脸约 6 分钟），全程自动，出完会自己放大检查并评级。

---

## 一、第一次使用：安装（每台电脑做一次，约 10 分钟）

1. **装 ChatGPT 桌面版**，用有 GPT 订阅（Plus 或以上）的账号登录。
2. **拿到工作台文件夹** `xhs-lock-studio`：装 the rumah小红书工作台时会自动放进「文稿 / 文档」（Mac `~/Documents/xhs-lock-studio`，Windows `C:\Users\你的用户名\Documents\xhs-lock-studio`）。模特照片、产品照片和参考图不在仓库里，找负责人要，放进 `library/` 对应的文件夹。
3. **在 ChatGPT 里建项目**：左侧栏「项目」旁边点「＋」→ 新建项目，文件夹选刚才的 `xhs-lock-studio`，项目名叫「锁图」。
4. **检查环境**：在「锁图」项目里新建一个聊天，顶部切到「工作」，发这句话：
   ```
   运行 python3 tools/check_env.py，缺什么就装什么，装好告诉我结果。
   ```
   看到「环境正常」就装好了。如果 Mac 弹窗问要不要安装「命令行开发者工具」，点「安装」，装完再发一次上面那句话。Windows 上把这句里的 `python3` 换成 `python`。
5. 输入框左下角的权限选「完全访问」，不然 Codex 每一步都要你点同意。

## 二、准备素材

素材分三类，各放各的文件夹，可以随意组合：

| 放什么 | 放在哪 | 多久做一次 |
|---|---|---|
| 模特 | `library/models/<模特名>/` | 每个模特一次 |
| 衣服 | `library/originals/<款名>/` | 每款衣服一次 |
| 想模仿的小红书图 | `library/references/` | 随时往里加 |

### 1. 模特（每个模特做一次）
复制 `library/models/示例模特`，改成她的名字，放入她本人的照片，**文件名要一模一样**：

| 文件名 | 是什么 |
|---|---|
| `face_1_front.jpg` | 正脸大头照：脸占画面一半以上，纯色背景，不戴眼镜帽子 |
| `face_2_half.jpg` | 半侧脸（转头约 45°）大头照 |
| `face_3_profile.jpg` | 全侧脸（转头 90°）大头照 |
| `face_closeup.jpg` | 正脸特写，只裁额头到下巴（可以从 face_1 裁） |

然后改写文件夹里的 `profile.md`：脸型、五官、发型、妆容逐项写，不会写可以让 Codex 帮忙（「看 library/models/小美 里的照片，按 profile.md 的格式帮我写」），写完自己核对一遍。

**三个角度都要有**：出图时会按素材图里脸的角度，挑最接近的那张本人照片把脸换上去。缺哪个角度，那个角度的图就最容易不像。

### 2. 衣服（每款衣服做一次）
复制 `library/originals/示例原图`，改成款名，放入：

| 文件名 | 是什么 | 必须吗 |
|---|---|---|
| `front.jpg` | 衣服正面（平铺或挂拍，纯色背景） | 必须 |
| `back.jpg` | 衣服背面 | 建议 |
| `detail_1.jpg` | 面料近拍，**要平铺拍**，不要把布拧成卷圈（卷圈会被画成图案） | 长毛、粗针、混色、半透明面料必须有 |
| `detail_2_<部位>.jpg` | 这件衣服**最有辨识度的设计**的特写（领口、扣子口袋、缝线），可以从 front.jpg 裁出来放大 | 强烈建议 |

然后按 `library/originals/产品档案模板.md` 写 `spec.md`（任何衣服都用这一套），重点是：
- **材质**：绒毛多长、针织粗细、混色比例、透不透光，这些最容易被画错。
- **关键设计**：写成「从哪开始、多宽、到哪结束、贴不贴身、它不是什么」。只写"有一块长叠片"会被画成丝巾。
- **检查要点**：分「必过」和「尽量」。颜色、材质、长度、领型、扣子口袋数量是必过；一两厘米的缝线拐角这类是尽量。
- 不会写可以让 Codex 帮忙：「看 library/originals/K01碎花裙 里的照片，按产品档案模板帮我写 spec.md」，写完自己对着照片检查一遍，**写错了它会把对的图判成不合格**。

### 3. 素材图
想模仿的小红书图直接放进 `library/references/`。竖图最好，横图会被裁掉两边。

## 三、每次出图（三步）

1. 用 Chrome 或 Edge 打开 `canvas.html`（双击就行），点「打开工作台文件夹」，选 `xhs-lock-studio`。
2. 选一款衣服，点选素材图（可以多选，一张素材出一张成品），「锁定范围」保持默认「锁产品 + 换成我们的模特」，选好模特。页面会提示缺什么照片。点「生成任务单」，再点「复制给 Codex 的指令」。
3. 回到 ChatGPT 的「锁图」项目，新建聊天，切到「工作」，粘贴指令发送。

出完前不用管。它会对每张图：换衣服 → 放大检查衣服（不合格自动从素材图重做）→ 贴模特本人的脸 → 融合 → 检查脸。

**想快一点**：多款衣服可以各开一个聊天同时跑，互不影响。但订阅额度有限，3 个聊天同时跑一小时大约用掉 5 小时额度的一半。

### 只出产品图（不用模特）
画布点「产品套图」：选一件衣服（同款多色就按顺序多选几个颜色文件夹），可选一张 `library/backgrounds/` 里的场景图，填每种图要几张，选 3:4 或 1:1，点「生成任务单」再复制指令给 Codex。
- 能出：挂拍正面/背面、平铺正面/背面、领口特写、面料特写、多色合拍。只有 `front.jpg` 也能出正面挂拍和平铺；有 `back.jpg` 才出背面，有面料近拍才出面料特写。
- 同款多色：每个颜色一个文件夹（比如 `K01针织衫_粉`、`K01针织衫_灰`），各放自己的照片。spec.md 至少写一个颜色，别的颜色可以借用。不同颜色的同一种图用同一个场景，一套图是统一的。

## 四、看结果

- 成品在 `jobs/<任务名>/out/`，已经是 1080×1440 的 3:4 图。
- `report.md` 里每张图都有评级：
  - **A**：衣服和脸都对，直接用。
  - **B**：衣服的必过项都对，只差小地方（缝线拐角被挡住、光线下妆色偏暖这类），**请看一眼**，觉得可以就用。
  - **C**：没通过，放进了 `rejected/`，写了原因。
- `compare.jpg` 是产品图、素材图和成品的并排总览；画布页面的「成品对比」页也能看。

## 五、常见问题

- **脸不太像**：看 `jobs/<任务名>/base/` 里的 `*_贴脸.png`，贴上去的脸角度和头差很多，说明缺这个角度的大头照，补拍后重出这一张。
- **衣服材质不对**（长毛变短、粗针变细、出现奇怪花纹）：检查 `detail_1.jpg` 是不是平铺拍的、`spec.md` 的材质有没有写清楚。
- **衣服细节不对**（扣子位置、领口、长度）：先核对 `spec.md` 写得对不对，再补一张对应部位的 `detail_2_*.jpg`。
- **眼镜、帽子样子变了**：在画布「补充要求」里写清楚，比如「保留素材图的黑色粗框圆眼镜」。
- **素材图是背影或脸被挡住**：会跳过换脸，只换衣服。
- **提示缺少 cv2 / PIL**：在「锁图」项目里发「运行 python3 tools/check_env.py」。
- **一直卡在 Thinking、报 502 或重连**：是 ChatGPT 服务或网络的问题，点停止，再发「接着做，从没完成的那一步继续」。
- **额度用完**：等额度恢复后，在同一个聊天里发「继续」。

## 其他模式（备用）
- **人和衣服都按原图**：原图文件夹里有模特穿着这件衣服的照片时可用，老流程，在画布「锁定范围」里选。
- **只锁产品，不换模特**：人还是素材图里那位，只能内部看效果，不能发布。
- **按背景换姿势**：画布「按背景换姿势」页，模特、产品、背景各选一张，自动设计姿势。
