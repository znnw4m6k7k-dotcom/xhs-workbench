# 模式 A：按背景换姿势（任务单「模式: 按背景换姿势」时用）

检查、评级、报错和交付按 SKILL.md 最后几节。

素材：`library/models/<模特>/`（`face.jpg`、`full_front.jpg`、`profile.md`），`library/products/<款号>/`（`front.jpg`、`back.jpg`、`detail_*.jpg`、`spec.md`），背景图。

## A1. 看背景，定姿势
判断场景类型、光线方向、地面或坐具在哪里、相机视角。姿势优先用 job.md 里写好的；一套图里至少要有 1 张正面全身，能看清衣服的完整长度和版型。

| 背景类型 | 推荐姿势 |
|---|---|
| 街道 / 墙面 | 正面站立、单手插兜；侧身回头；走路抓拍；靠墙单腿微屈 |
| 咖啡店 / 室内 | 坐姿侧身（下装别被桌子挡住）；站在窗边半侧身；拿杯子半身 |
| 户外草地 / 海边 | 走路回眸；双手提裙摆（只限裙装）；背影看远方；半蹲 |
| 楼梯 / 台阶 | 坐在台阶上；上台阶时回头；扶栏杆站立 |
| 纯色 / 影棚 | 正面全身；45° 侧身；背面全身；腰部以上特写 |

## A2. 提示词模板
```
图1-2 是模特【模特名】本人（脸部特写 + 正面全身），生成的人必须是同一个人：脸型、五官、发型、发色、肤色、身高比例、体型完全一致。
图3 起是产品【款号】的原图和细节图，模特身上穿的必须就是这件衣服，逐项还原：
【粘贴 spec.md「锁定参数」全文】
最后一张是背景图。把人物自然放进这个场景，光线方向、色温、阴影和背景一致，背景内容不要改。
姿势：【姿势描述】。构图：竖图，【全身 / 七分身 / 半身】，衣服完整入镜，人物头顶和脚下留出空间。
禁止：改变衣服的任何细节；改变模特的脸和身材比例；在图上加文字或水印。
```
