# 产品套图（任务单「模式: 产品套图」时用，不用模特）

一件衣服一键出一套产品图：挂拍、平铺、领口特写、面料特写，同款多色时再加多色合拍。只要有 `front.jpg`，有 `back.jpg` 就能出背面，有 `detail_2_*`、平铺面料图就能出特写。检查、评级、报错和交付按 SKILL.md 最后几节。

**为什么这样做**：产品照片当编辑底图（`编辑图1`），模型会保住这件衣服本身，只换场景和摆放方式；让它凭描述全新画一件，颜色、针织纹理和扣子位置最容易跑偏。多色合拍没有单张底图，每个颜色的正面图都附上，并在提示词里写死件数和每件的颜色。

## 第 0 步：出图前
1. `python3 tools/check_env.py`。
2. 读任务单「颜色」那一行列出的每个原图目录，看照片和 `spec.md`。某个颜色没有 spec.md 时，脚本会借用另一个颜色的描述，颜色只按它自己的照片。
3. 面料近拍是拧成卷圈或堆成褶拍的、又没有 `detail_1_flat.jpg` 时，裁一块平整的区域存成 `detail_1_flat.jpg`。

## 第 1 步：逐张出图
```
python3 tools/build_prompt.py product jobs/<任务> <序号>
```
它按任务单那一行的「类型」「原图目录」「第几种场景」拼好提示词和附图，存到 `jobs/<任务>/prompts/<序号>_product.json`。读这个 JSON，原样调用 image_gen，把生成的图复制到 JSON 里的 `save_as`（直接是 `out/<输出文件名>`）。提示词不要自己改写。

- 「第几种场景」决定用哪个内置场景（衣架、墙面、床单、地板等）。不同颜色的同一个序号用同一个场景，所以一套多色图看起来是统一的；任务单写了「场景背景」时，挂拍和平铺都放进那张背景图的场景里。
- 多色合拍：奇数张是挂成一排，偶数张是平铺在一起。一张最多放 5 个颜色（有场景背景时 4 个）。

## 第 2 步：检查
按 SKILL.md「检查」的衣服部分，和**这个颜色自己的** `front.jpg`、`detail_2_*`、平铺面料图并排放大看。另外查：
- 衣服整件完整入镜，没有被裁掉袖子、下摆；挂拍的衣架、平铺的俯拍角度对。
- 没有人、手、人台；没有文字、水印，领标和吊牌上没有画出字。
- 道具没有压住衣服，没有把衣服挡住超过一小角。
- 特写：结构和纹理和原图那一块一样，不是另画了一块相似的。
- 多色合拍：件数对，每件的颜色和它自己的照片一致，没有串色，几件的款式完全一样。

评级按 SKILL.md：必过项有一条不对是 C，加 `--fix "上一张的问题"` 重跑第 1 步，最多 3 次；只差小地方评 B，写进报告不返工。

## 第 3 步：交付
`python3 tools/contact_sheet.py jobs/<任务>`（按任务单的比例统一成 1080×1440 或 1080×1080，并生成总览），再按 SKILL.md「交付」写 report.md，一张成品一行。
