# 模式 B：参考图换人（老流程，任务单「模式: 参考图换人」时用）

日常出图用 SKILL.md 的「换模特」流程。这份只在原图目录里有模特本人穿着这件衣服的照片、要「人和衣服都按原图」时用。检查、评级、报错和交付按 SKILL.md 最后几节。

## B0. 先判断原图目录属于哪种素材，再决定流程
锁脸最稳的输入是「这位模特穿着这件衣服的照片」：测试里有上身原图时，脸只在侧脸那几张有偏差；只有脸部证件照加产品平铺图时，5 张成品的脸全部被换成了另一张更瘦、更尖的脸，衣服在身上的样子也只能靠推测。所以没有上身原图时，先补一张出来再换场景。

**为什么会出网红脸（几轮实测和运行记录确认的结论）**：
- 生图模型编辑一张图时，会保住底图那张脸的脸型骨架。把素材图当底图，出来是素材图那个人；让它全新生成，脸是它自己画的"默认好看的脸"（瓜子脸、尖下巴、高鼻梁），侧脸、大笑、远景小脸时最明显。
- 出图后再让它修脸，提示词写多具体（下巴改圆、下颌加宽）都改不动骨架，只会改皮肤和妆。
- 反过来，**底图里已经是她本人的脸，模型就会保住**：本人照片当底图做定妆照、本人照片贴到场景图上再融合，脸都是她。所以场景图一律走 B3 的三步：先出底图，再贴真脸，最后只融合。
- 工具限制：一次最多 5 张参考图；没有生成/编辑开关，也没有 input_fidelity、蒙版这类保脸参数。

| 原图目录里有什么 | 流程 |
|---|---|
| `original.jpg`（模特穿着这件衣服） | 直接走 B1–B4。另外用 `crop_compare.py closeup` 从 original.jpg 裁一张 `face_closeup.jpg`，原图里脸太小时检查和生成都靠它认人 |
| `anchor.jpg`（之前做好并检查通过的定妆照） | 当成 original.jpg 用，走 B1–B4 |
| `face*.jpg` + `front.jpg`（脸部图加产品图，没有上身照） | 先做第 0 步「定妆照」，通过后存为 `anchor.jpg`，再走 B1–B4 |
| 模特穿着别的衣服的照片 + 产品图 | 模特照只用来认人，按「脸部图 + 产品图」处理，先做定妆照 |
| 只有一张正脸，没有半侧和全侧 | 照常做，但素材图是侧脸或低头时脸最容易变，在 report.md 里提醒用户补拍半侧和全侧 |
| 没有 back.jpg 或细节图 | 照常做；素材图露出衣服背面时，背面按 spec.md 写的来，并在 report.md 里写明是推测 |
| 脸部图是多张拼在一起的 | 先拆开：正脸裁成 `face_closeup.jpg`（只包含额头到下巴），半侧、全侧分别存成 `face_2_*.jpg`、`face_3_*.jpg` |

**第 0 步：定妆照**（只在没有上身原图时做）
用「本人照片当底图」的方式做，不要全新生成全身照（脸会太小，见上面的根因）。
- 附图（最多 5 张）：图1 是模特本人正面胸像（`face_1_*`，没有就用 `face.jpg` 里裁出的正面）→ `face_closeup` → `front` → `detail_1`；背面是素面时靠 spec 文字描述，不附 back。
- 提示词明确写「编辑图1」：图1 里她的脸、五官、发型、肤色、表情、头部大小和位置都保持原样不要重画；只把她身上的衣服换成图3 这件（锁定参数全文），再把画面向下延伸成从头顶到大腿中部的 3:4 半身照，下装按任务单，浅灰影棚背景。
- 按「检查」一节逐项查，脸用 `crop_compare.py check`。最多 3 次，通过的存成原图目录里的 `anchor.jpg`，在 report.md 里写明。
- 3 次都不通过就停下来，把对比图放进 report.md，请用户挑一张或者补一张本人穿这件衣服的照片。脸部特征全部对上、只差发丝走向或光线这类同一个人换张照片也会变的地方，写明差异后交给用户确认，不要直接丢弃。

## B1. 读素材
读原图目录下的 `spec.md` 和全部图片，记住模特的脸、发型、身材比例，以及整套穿搭。然后逐张看素材图，记下每张的动作（身体朝向、重心、四肢角度、手放在哪、头的方向）、机位（平视、俯拍、仰拍、全身还是半身）、场景、光线方向和配饰。

**spec.md 怎么写才锁得住**（发现 spec 写得笼统时，先补全再出图）：
- 脸要写能区分这个人的特征，不要写"漂亮、精致"。逐项写：脸型（圆、方、长，下颌角和下巴的形状）、眉形、眼型和双眼皮宽窄、眼距、鼻梁高低和鼻头大小、嘴唇厚薄、雀斑痣、发色发型刘海。
- 再单独写一行侧脸：额头斜度、鼻梁弧度和鼻尖、嘴唇突出程度、下巴前后位置、下颌角。素材图是侧脸时，第 3 步融合会用到。
- 写一行"不要"，把生图最常见的走样写进去：瘦脸、尖下巴、高鼻梁、放大眼睛、欧式深双眼皮、网红脸。
- 本人照片要有三个角度：`face_1_*` 正脸、`face_2_*` 半侧、`face_3_*` 全侧（大头照，脸占画面一半以上，纯色背景）。第 2 步贴脸按角度挑照片，缺哪个角度，那个角度的素材图就最容易不像。
- 衣服上不对称的设计要同时写「穿着者的左/右」和「正面看在画面的左/右」，对镜自拍时左右会反过来。
- **关键设计怎么写**（衣服最容易跑偏的地方，模式 C 实测）：只写"有一块长叠片"，模型会把它画成丝巾或飘带。要写成几何描述：
  - 起点：从哪里开始、和什么连在一起（比如"上端缝在立领断口里"）
  - 形状和大小：用身体当尺子（"约一个手掌宽、占前胸 1/4"），宽度变不变
  - 走向和终点：贴身还是飘起、到哪里结束（"贴着衣身垂到下摆，和下摆齐平"）
  - 它不是什么：最容易被画成的样子都写进去（"不是丝巾、飘带、领带，不能是窄条"）
  - 侧面看是什么样：侧身素材图要靠这一句
  - 最后单独列一节「检查要点」，每条都能放大看一眼就判对错
- 领型要写清有没有翻领和领尖，袖口写清扣子数量。

## B2. 素材图里的衣服和原图不一样时怎么处理
- 有上身原图时，成品里的**整套穿搭以原图为准**，包括上衣、下装和鞋子。素材图里人物的衣服一律不要。
- 只有产品图（front/back）、没有上身原图时，只替换这件产品；产品覆盖不到的部位（比如产品是上衣，下装和鞋）保留素材图里的，除非 spec.md 另有规定。按 spec.md 写的版型和衣长穿到身上，这部分是推测，要在 report.md 里写明。
- 产品图里的品牌织标、吊牌上的字不要画进成品。
- 素材图里那个人穿的是长款，原图是短款（或者反过来），就按原图的长度来，被露出来或遮住的身体部分要自然补全。
- 配饰和道具按 spec.md 写的来；spec.md 没写时，保留素材图里对应的配饰和道具（眼镜、帽子、包、手机、首饰），这是用户的默认偏好。配饰不能挡住衣服的印花、logo、扣子、领口设计这些关键部位，挡住了就调整位置。
- 素材图人物的**妆容**不要带进来（眼影颜色、口红颜色、眼线形状），妆容按原图模特的来。测试里出现过素材图的蓝色眼影被带进成品。

## B3. 三步出图（每张素材图都走一遍）
生图模型编辑一张图时，会保住**底图那张脸**的脸型骨架：底图是谁，出来就像谁。直接按素材图出的图，脸是模型自己画的（侧脸、大笑、远景尤其明显，会变成瓜子脸、尖下巴），事后怎么写提示词修都改不回来。所以脸单独处理：

1. **出底图**：按素材图出动作、场景、衣服和比例都对的图，脸先不管。
2. **贴真脸**：`tools/face_paste.py` 把本人照片里角度最接近的那张脸，对准贴到底图的头部放大图上。
3. **融合**：把贴好脸的头部图交给生图模型，只修接缝、光线和表情，再用 `tools/face_fix.py paste` 贴回底图。

素材图里看不到脸（背影、脸被手机或头发完全挡住）时，只做第 1 步。

### 第 1 步：出底图
附图（一次最多 5 张，按这个顺序；任务单「第 1 步附图」照这个写）：
1. 图1：这一张对应的素材图（只取动作、机位、构图、场景、光线、配饰）
2. 图2：`original.jpg` 或 `anchor.jpg`（人和整套衣服）
3. 图3：`front.jpg`（衣服正面）
4. 图4：`detail_*.jpg`（面料和关键细节）
5. 图5：素材图露出背面时用 `back.jpg`；否则用 `body_1_*`（全身比例照），都没有就用 `face_closeup.jpg`

提示词：
```
图1 是素材图，只用它的动作、机位、构图、场景、光线和配饰。不要把图1当编辑底图，要生成一张新照片。
图2 起是模特【名称】和她穿的衣服，是成品里人物和衣服的唯一依据。

1. 背景、构图、相机角度和光线照着图1；人物动作和图1一致：身体朝向、重心、四肢角度、手的位置、头的方向和角度、视线方向。头在画面里的大小和位置也和图1一致。
2. 人物换成图2的模特：发型、发色、肤色按图2，脸尽量接近图2（脸之后会单独替换成本人，这一步重点是头的角度和位置准确）。图1那个人的衣服、妆容都不要保留。
3. 衣服逐项还原（这是这一步最重要的）：
【粘贴 spec.md「锁定参数」里衣服、下装和鞋、配饰的全文】
4. 比例：任务单写「按原图」时，头身比、肩宽、腿长按图2；写「按素材图」时身体轮廓沿用图1的人。人物大小符合图1的场景透视。
5. 竖图，人物头顶和脚下留出空间，之后裁成 3:4。小红书真实穿搭照的质感，像手机随手拍，不要影棚精修感。

禁止：改变衣服的颜色、材质光泽、长度、版型、纹路方向、印花、logo、扣子数量、口袋、领型；把图1人物的衣服带进来；大头、短腿、拉长腿、手指畸形；文字和水印。
```
出完先按「检查」只查**衣服、动作、比例、画面**（脸这时还不用查）。有一项不过就重出这一步，返工时用「修正办法」里的 Freeze 写法，最多 3 次。通过后存成 `jobs/<任务>/base/<输出文件名>`。

### 第 2 步：贴真脸
```
python3 tools/face_paste.py jobs/<任务>/base/<文件名>.png library/originals/<名称>
```
它会生成 `<文件名>_head.png`（头部放大图）、`<文件名>_head.json`（贴回位置）和 `<文件名>_贴脸.png`，并打印用了哪张本人照片、脸多大、什么角度。
- 提示「没找到人脸」：素材图是背影或脸被挡住，跳过第 2、3 步，底图直接当成品。
- 打开 `_贴脸.png` 看一眼：脸的位置、角度要和头发、脖子大致对上。角度明显不对（比如头是侧的、贴上去的是正脸）时，说明原图目录缺这个角度的本人照片，在 report.md 里提醒用户补拍，这张照常做下去。
- 第一次运行提示缺少 cv2 时，先 `pip3 install opencv-python numpy pillow`。

### 第 3 步：融合
提示词可以直接用 `python3 tools/build_prompt.py fuse jobs/<任务> <序号> --light ... --expr ... [--acc ...]` 拼（会读原图目录 spec.md 里的脸型和妆容），和下面的模板是同一份。
附图**只有 2 张**：
1. 图1：`<文件名>_贴脸.png`（要编辑的底图）
2. 图2：`face_closeup.jpg`（她本人）

**不要附第 1 步的底图、`_head.png` 或素材图。** 实测附了贴脸前的那张图，模型会把脸改回那张网红脸。

提示词（照抄，只替换【】里的内容）：
```
编辑图1，只做局部修补。图1 中间这张脸就是模特本人（和图2是同一个人），这张脸已经是对的：【spec.md 或 profile.md 里脸型、下巴、下颌那一句，原样照抄】。
脸型、颧骨、眉毛、眼睛形状和大小、鼻子、嘴唇形状都保持图1的样子，不要重画。不要美化、瘦脸、削尖下巴、放大眼睛，不要把脸改得更像网红或模特。

只修这几处：
1. 脸的边缘和周围（头发、耳朵、脖子、背景）之间的接缝、硬边、色差，修成自然过渡；脸周围断掉的发丝接成自然连贯的头发；脸边缘露出的灰色影棚背景改成和周围一致的背景。
2. 脸上的光线方向、色温、明暗、清晰度和颗粒感，调成和图1其余部分一致（【素材图的光线，比如户外强日光、室内暖光】的手机照片），保留毛孔、雀斑和皮肤纹理，不要磨皮。
3. 妆容按图2：【spec.md 里的妆容描述】。
4. 表情：【看素材图写出来，比如「开心地张嘴大笑、露出上排牙齿、眼睛笑得微微眯起」「嘴角微微上扬的浅笑」「放松的自然表情，不笑」】；只动嘴巴、笑肌和眼周，脸型、下巴和五官比例仍然是图1这张脸。
5. 配饰：【素材图里头脸上的配饰，比如「戴黑色细框眼镜」「戴卡其色棒球帽，帽檐压在额头上」；没有就删掉这一条】，按素材图的样子补在她脸上，不要遮住眼睛以外的五官。
头的位置、角度、大小、视线、头发和背景构图都和图1一致。输出和图1同样大小的正方形图，不要裁切、不要缩放。
```
然后贴回：
```
python3 tools/face_fix.py paste jobs/<任务>/base/<文件名>.png <融合结果>.png
```
得到 `<文件名>_fixed.png`，按「检查」查脸。脸没过就重做第 3 步（最多 2 次，返工时把对照表里不一致的格子写进第 4 条后面）；还不过，看是不是第 2 步贴的角度不对，在 report.md 里写明，请用户补对应角度的本人照片。通过后存成 `out/<输出文件名>`。

## B4. 附图规则汇总
- 内置 image_gen 一次最多附 5 张图（多了直接报错），不要拼图来塞更多张，拼图会把每张缩小。
- 第 1 步管衣服和动作，第 3 步管脸，两步的附图不要混用。
- 身份依据只用原图目录里的本人照片，**不要拿之前生成的图当身份参考**（会越传越不像）。

## 脸不像怎么办
1. 先看 `_贴脸.png`：贴上去的照片角度和头的角度差很多，是原图目录缺这个角度的本人照片，请用户补拍。
2. 贴脸没问题、融合后变了：重做第 3 步，把对照表里不一致的格子写进提示词第 4 条后面，比如"融合后下巴变尖了，保持图1里短而圆的下巴"。确认附图只有贴脸图和 face_closeup 两张。
