# 锁图出图流程

先读 `jobs/<任务>/job.md`：
- 「模式: 只锁产品」：按本文件做。「脸部处理」写「换成我们的模特 library/models/<名字>」时走全部 5 步；写保留、AI 脸、不露脸时见最后「其他脸部处理」。
- 「模式: 参考图换人」：读 `modes/模式B_参考图换人.md`。
- 「模式: 按背景换姿势」：读 `modes/模式A_按背景换姿势.md`。
- 「模式: 产品套图」（不用模特，只出挂拍、平铺、特写、多色图）：读 `modes/产品套图.md`。
各个模式都用本文件最后的「检查」「返工」「生图报错和断线」「交付」几节。

**为什么这样做（实测结论，别改）**
- 生图模型编辑一张图时，会保住底图那张脸的骨架。素材图当底图，人、动作、场景最自然；脸要换成我们的模特，只能把她本人照片**贴上去**再让模型只融合。全新生成或事后修脸，都会变成瓜子脸、尖下巴的网红脸。
- 融合只附贴脸图和 `face_closeup.jpg` 两张。附了贴脸前的图，脸会变回原来那张。
- 衣服走样集中在：最有辨识度的那个设计（写含糊会被画成丝巾）、特殊材质（长毛被抹平、卷圈面料照被画成卷圈纹、素材原衣服的长毛渗到新衣服上）。所以要有关键设计特写和平铺面料图，提示词里有材质隔离句。
- 在上一张成品上反复修，面料和皮肤一次比一次假。返工一律从素材图重做。
- 一次最多附 5 张图（多了直接报错），不要拼图。没有蒙版、保脸强度这类参数。

**提示词不要自己写**：换衣服和融合的提示词都用 `tools/build_prompt.py` 拼，它会原样带上 spec.md 和 profile.md 的内容，并按任务单排好附图。你只负责看素材图、填空。返工也是同一条命令加 `--fix`，不要缩写或改写它拼出来的提示词。

## 第 0 步：出图前（每个任务做一次）
1. `python3 tools/check_env.py`。
2. 读原图目录的 `spec.md` 和模特文件夹的 `profile.md`，看一遍产品照片和模特照片。
3. spec 缺「材质」「关键设计」或「检查要点」时，按 `library/originals/产品档案模板.md` 看照片补一版，report.md 开头写「spec 是我按照片写的，请检查」。
4. 没有关键设计特写 `detail_2_*.jpg` 时，从 `front.jpg` 把这一块裁出来放大存一张。面料近拍是拧成卷圈或堆成大褶拍的、又没有 `detail_1_flat.jpg` 时，裁一块平整的区域存成 `detail_1_flat.jpg`。补了图的话，告诉用户在画布上重新生成任务单（附图清单是任务单定的）。
5. 逐张看素材图，记下：人物原来穿的衣服和材质（`--old`），是不是侧身（`--side`）、对镜自拍（`--mirror`），光线，表情，头脸上的配饰。素材图是背影、或关键设计会被手臂、包、头发挡住时，report 里写明「这张看不到 XX」，评级最高 B。

## 第 1 步：换衣服和发型
```
python3 tools/build_prompt.py clothes jobs/<任务> <序号> --old "米白色长毛开衫" [--side] [--mirror]
```
它把提示词和附图存到 `jobs/<任务>/prompts/<序号>_clothes.json`。读这个 JSON，原样调用：
```
const j=JSON.parse((await tools.exec_command({cmd:"cat jobs/<任务>/prompts/01_clothes.json"})).output);
await tools.image_gen__imagegen({prompt:j.prompt, referenced_image_paths:j.referenced_image_paths});
```
生成的图默认在 `~/.codex/generated_images/` 里，把它复制到 JSON 里的 `save_as`（`jobs/<任务>/base/<输出文件名>`）。

## 第 2 步：查衣服
按下面「检查」的衣服部分查，脸这时不用查。必过项有一条不对就按「返工」重做第 1 步，最多 3 次。通过了才往下走。

## 第 3 步：贴真脸
```
python3 tools/face_paste.py jobs/<任务>/base/<文件名>.png library/models/<名字>
```
得到 `<文件名>_贴脸.png` 和 `_head.json`，它会打印用了哪张本人照片、脸的角度。打开 `_贴脸.png` 看一眼：脸的位置、角度要和头发、脖子大致对上；对不上说明缺这个角度的本人照片，report 里提醒用户补拍，这张照常做。提示「没找到人脸」（背影、挡脸）就跳过第 3、4 步，第 1 步的图直接当成品。

## 第 4 步：融合
```
python3 tools/build_prompt.py fuse jobs/<任务> <序号> --light "户外强日光" --expr "开心地张嘴大笑、露出上排牙齿、眼睛微微眯起" [--acc "黑色粗框圆眼镜，实色镜框"]
```
- `--expr` 照素材图写，具体到嘴和眼睛。`--acc` 先放大素材图看清楚：眼镜写框型（圆、方、猫眼）、粗细、颜色、透明还是实色，帽子写颜色和帽檐压到哪；只写「戴眼镜」会被画成别的眼镜。没有配饰就不写。
- 同样读 `prompts/<序号>_fuse.json` 原样调用 image_gen，结果同样复制到 `save_as`（`base/<文件名>_融合.png`）。
- 贴回：`python3 tools/face_fix.py paste jobs/<任务>/base/<文件名>.png jobs/<任务>/base/<文件名>_融合.png`，得到 `_fixed.png`。

## 第 5 步：查脸
按「检查」的脸部分查，在融合结果（放大的正方形头部图）上看，贴回后的整图只确认没有接缝和色差。没过就重做第 4 步，加 `--fix "融合后下巴变尖了，保持图1里短而圆的下巴"`，最多 2 次；还不过，看是不是第 3 步贴的角度不对，report 里请用户补对应角度的照片。通过后 `_fixed.png` 存成 `out/<输出文件名>`。

### 其他脸部处理
- **保留**：只做第 0~2 步。脸是素材图那位真人的，只能内部看，report.md 开头写明不能发布。
- **换 AI 脸**：第 2 步通过后再编辑一次，只附成品一张图：「编辑图1，只把人物的脸换成一张普通的、不对应任何真人或明星的亚洲女性面孔，五官自然不网红；头的角度、表情、视线、发型、身体、衣服和背景全部不动。」检查新脸和素材图那个人明显不是同一个人。
- **不露脸**：第 1 步加 `--keep "画面从人物嘴巴以下开始，看不到眼睛和鼻子"`，或素材图本来用手机挡脸时保持挡住。

## 检查
**先找不同，再打勾**，不能只看整张缩略图就判断。
1. `python3 tools/crop_compare.py grid <成品>.png`，在带坐标的图上读出脸和衣服关键部位的框。
2. `python3 tools/crop_compare.py check jobs/<任务> <成品>.png --face x1,y1,x2,y2 --garment x1,y1,x2,y2`，看生成的 `check/<成品>.jpg`。关键设计和面料各放大一块，和 `detail_2_*`、平铺面料图并排看。

### 衣服
1. **先查材质有没有被素材带偏**：成品衣服放大、素材原来衣服放大、平铺面料图三张并排。成品的绒毛长短、针眼粗细、光泽更像素材原来那件，就是 C。
2. **逐条查 spec 的「检查要点」**，每条写「对 / 不对 / 看不到」。「必过」（颜色、材质、廓形、长度、领型、数得出来的扣子口袋）有一条不对就是 C；「尽量」（缝线拐角、罗纹宽度这类一两厘米的小结构）不对评 B，不为它返工。
3. 再看：人物的脸、身材、动作、手、腿和背景跟素材图比没有被改；衣服光影和素材图一致、不像贴上去的；比例正常，手指脚没有畸形；没有接缝、多余肢体或文字；不对称设计在正确的一侧（对镜自拍左右相反）。

### 脸
和模特本人照片比这几项：脸型宽窄和下巴、眉形、眼睛大小和双眼皮、鼻梁和鼻头、嘴唇、妆容、发色发型。每项写「一致」、哪里不同，或者「看不到」（被挡住、太小）。另外看表情是否跟素材图一致、配饰是否和素材图一样。

### 评级
- **A**：衣服必过项都对；脸上**看得到的**几项都一致。被头发、帽檐、眼镜挡住而「看不到」的不影响 A。
- **B**：衣服必过项都对，只差「尽量」项、关键设计被挡住，或者脸只差同一个人换张照片也会变的地方（发丝走向、光线下妆的浓淡、表情带来的眼睛大小变化）、配饰样子和素材图有出入。存进 `out/`，report 里写明请用户看哪一处，不要反复重出。
- **C**：衣服必过项有一条不对，或脸上看得到的五官结构有一项不同。移到 `rejected/`，文件名后加上没通过的项目，按「返工」重做。

## 返工
- 一律从素材图重做：衣服重跑 `build_prompt.py clothes ... --fix "上一张的问题"`，融合重跑 `build_prompt.py fuse ... --fix "..."`。不要在上一张成品上继续改，不要拿之前生成的图当身份参考。
- `--fix` 只写没通过的那一项，比如「袖口扣子画成了 1 颗，原图每个袖口 2 颗」。
- 改下装或局部时动作跟着变了：加 `--keep "双腿的位置、步态、哪只脚抬起、脚尖朝向、膝盖弯曲角度都和图1完全一样"`，返工后和素材图并排看一次腿和手，动作变了也算 C。
- 关键设计变形（比如垂片变成丝巾）：先补 spec 的几何描述和检查要点、补一张这一块的特写，再重出。只加 `--fix` 不补特写，同样的错会再出。
- 同一张连续 3 次 C：停下来，在 report.md 里写明原因。常见原因是素材里看不到这个角度的衣服或脸，建议用户换素材或补拍。

## 生图报错和断线
生图返回 502、Bad Gateway、ECONNRESET、UND_ERR_SOCKET、响应流 EOF 这类网络错误时，没有出图，不算一次质量返工：等 20 秒，用**完全相同的提示词和附图**重试，最多 3 次，不用问用户。3 次都失败才停下来，在 report.md 写明卡在哪一张哪一步，告诉用户等网络恢复后发「继续」。
用户发「继续」时，先看 `base/`、`out/` 里已经有哪些文件（底图、`_贴脸.png`、`_融合.png`、`_fixed.png`），从缺的那一步接着做，已经有的结果不要重新生成。

## 交付
1. 运行 `python3 tools/contact_sheet.py jobs/<任务>`，成品统一成 1080×1440，并生成对比总览 `compare.jpg`。
2. 写 `report.md`，短一点，用户要的是哪几张要看：
   - 开头：模式、脸部处理；换模特时加一句「身材和构图来自素材图那张别人的照片，能不能发布由你判断」。
   - 一张表，每张成品一行：`| 成品 | 素材图 | 评级 | 返工次数 | 要你看的地方（B 写哪一处，A 写「无」）| 对比图 |`，对比图写 `check/` 里的文件。
   - C 级没能交付的单独列一行原因。脸部逐项结果和衣服逐条结果是你自己判断用的，不用整张表抄进报告。
