# 小红书锁图工作台：Codex 必须遵守的规则

这个文件夹用来给服装产品出小红书图。每一张图都必须做到：**模特是同一个人，衣服是同一件衣服，模特的身材比例正常。**
接到出图任务时，先运行 `python3 tools/check_env.py`（缺库会自动安装；**Windows 上本文件夹里所有 `python3` / `pip3` 都换成 `python` / `pip`，找不到再试 `py -3`**），再读 `.agents/skills/xhs-lock/SKILL.md`，然后按里面的流程执行。任务单 `job.md` 第一行下面的「模式」决定用哪个流程。

## 几种模式
- **推荐：模式 C + 换成我们的模特**。任务单写「模式: 只锁产品」且「脸部处理: 换成我们的模特 library/models/<名字>」。素材图当底图，人、动作、身材、场景跟素材图；衣服换成 `library/originals/<款>/` 的产品；脸和发型换成 `library/models/<名字>/` 里的模特（先换衣服过检查，再贴她本人照片的脸、只做融合）。按 SKILL.md 的 5 步做。
- **产品套图（不用模特）**。任务单写「模式: 产品套图」。用产品照片当底图，出挂拍、平铺、领口和面料特写、同款多色合拍，按 `.agents/skills/xhs-lock/modes/产品套图.md` 做。
- **模式 B：参考图换人**。输入是「模特穿着产品」的原图，加上若干张素材图。每张素材图出一张成品：成品的动作、机位、构图和场景跟素材图一致，但图里的人换成原图里的模特，衣服换成原图里的衣服。
- **模式 C：只锁产品，不换模特**。人、脸都用素材图原样，只换衣服。人是素材图里的真人，只能内部看，发布前要换成我们的模特、AI 脸或不露脸。
- **模式 A：按背景换姿势**。输入是模特图、产品图和背景图，按背景自动设计不同姿势。

## 目录约定
- `library/models/<模特名>/`：一个模特一个文件夹，只放她本人的照片（`face_1_front.jpg` 正脸、`face_2_half.jpg` 半侧、`face_3_profile.jpg` 全侧、`face_closeup.jpg` 正脸特写，可选 `body_*`）和 `profile.md`（脸型、五官、发型、妆容、不要什么）。任何衣服都能配任何模特。
- `library/originals/<名称>/`（模式 B）：`original.jpg` 是模特穿着产品的原图；可以再放 `original_2.jpg` 等其他角度。没有上身原图时，改放脸部图加 `front.jpg`、`back.jpg`（产品平铺或挂拍图），出图前先按 SKILL.md 第 0 步做一张定妆照，检查通过后存成 `anchor.jpg`，之后当上身原图用。脸部图用 `face_closeup.jpg`（正脸特写，只含额头到下巴）加 `face_2_*.jpg`、`face_3_*.jpg`（半侧、全侧）；拼在一起的脸部图要先拆开。`detail_*.jpg` 是衣服细节特写。外加 `spec.md`，写模特特征和衣服的锁定参数。
- `library/references/`（模式 B）：素材图，也就是想要模仿的动作和场景。
- `library/models/<模特名>/`、`library/products/<款号>/`、`library/backgrounds/`（模式 A）：模特图、产品图、背景图，格式见 SKILL.md。
- `jobs/<日期>_<名称>/`：每次出图的任务目录。`job.md` 是画布页面生成的任务单，`out/` 放成品，`rejected/` 放检查没通过的图。

## 硬性规则（任何一条都不能违反）
1. 每次调用生图，都必须**同时附上**任务单里这一步列出的全部图片，并按列出的顺序附上。不允许只用文字描述代替参考图。内置 image_gen 一次**最多只能附 5 张图**（超过会直接报错 `referenced_image_paths must contain at most 5 paths`），不要拼图。模式 B 每张图分三步（出底图、贴真脸、融合），各步附图不同，按 `.agents/skills/xhs-lock/modes/模式B_参考图换人.md` 来；融合**只附贴脸图和 face_closeup 两张**，附了贴脸前的图脸会变回网红脸。
2. 默认流程的换衣服和融合提示词一律用 `tools/build_prompt.py` 拼，原样使用，不能改写、删减或"优化"，返工只加 `--fix`。模式 B 第 1 步、模式 A 的提示词必须原样包含 `spec.md` 里"锁定参数"一节的全部内容。
3. 模特的脸、发型、肤色，以及衣服的材质、颜色、款式、长度、纹路、印花、logo、扣子、口袋、领型、袖长，全部以原图为准，不能改变。模式 B 只从素材图里取动作、机位、构图、场景和光线，素材图里那个人的脸、妆容和衣服不能带进成品，身材是否沿用看任务单的「身材比例」，配饰按 spec.md。模式 C 相反：素材图里的人、脸、身材、动作、场景全部原样保留，只换衣服。生图模型会把脸往瘦脸、尖下巴、高鼻梁、大眼睛的方向美化，这也算换脸。
4. 比例必须正常。任务单「身材比例」写「按原图」时，头身比、肩宽、腿长和原图模特一致；写「按素材图」时，身材和比例沿用素材图里的人，但脸、发型和衣服仍然以原图为准。人物大小要符合场景透视；不能出现大头、短腿、拉长腿或手脚畸形。
5. 表情和神态要自然，不能僵硬。任务单「表情」写「跟素材图」时，表情、视线和放松程度跟素材图里的人一致（素材图在笑就笑），但五官仍然是原图模特的；脸部参考图是影棚证件照式的，只用来认人，不要照搬它的呆板表情。
6. 一次只生成一张图，每张图生成完马上按 SKILL.md 的「检查」放大并排对比（`tools/crop_compare.py`），逐项写出哪里一致、哪里不同，评 A/B/C，不能只看整张图就判断「是同一个人」。C 级移到 `rejected/` 并写明原因，再按「返工」重做，同一张最多重试 3 次；B 级（五官结构一致，只差发丝、光线、妆的浓淡这类）放进成品并在 report.md 里请用户确认，不要反复重出。
7. 输出 3:4 竖图，按 1080×1440 交付，生成时人物头顶和脚下都要留出空间，方便裁成 3:4。文件名用任务单里写好的名字。
8. 不要在图里加文字、水印或贴纸，也不要美化衣服（比如把褶皱抚平、把面料改得更亮、改短裙长）。
9. 最后把成品清单和检查结果写进任务目录的 `report.md`。
