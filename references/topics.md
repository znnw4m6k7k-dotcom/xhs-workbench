# 女装选题方法

写给 AI 看的出选题手册。

## 好选题的标准

- **一句话 ≤25 字**，能直接当标题的方向。
- **有具体的人和具体的问题**：身高/身材 + 场景 + 困扰。`155 小个子冬天穿长大衣怎么不被吞` 比 `大衣穿搭分享` 好。
- **能用这批图写**：主要是对镜自拍和街拍，选题要能用上身图回答。
- **真实在问**：先联网看最近小红书、搜索联想、评论区里大家在问什么，从真实痛点出发，不凭空编。

## 常用角度

1. 身材避坑：`梨形别买这 3 种半裙`
2. 场景一套搞定：`周一早八通勤不想动脑就穿这套`
3. 一衣多穿：`一件黑针织我穿了 5 种`
4. 面料/细节讲透：`为什么这件羊毛衫贴身不扎`
5. 季节/节点：提前 2–3 周出，`双 11 前先看看这 3 件值不值`
6. 选码答疑：`160 48kg 到底穿 S 还是 M`

## 铺开方法

- 按「场景 × 身材」格子，优先补空格子。
- 同一批里角度不要重复，不和已有选题、已发标题撞题。
- 每条附一句 why：这个痛点从哪来（例：评论区常问、搜索联想靠前）。
